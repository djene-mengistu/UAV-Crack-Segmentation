# Attribution

This release provides a compact PyTorch implementation compatible with the author's trained MiT/UPer checkpoints. It does not vendor the original ProMSC or SegFormer source trees. Checkpoint names and tensor shapes preserve compatibility. Architectural and loss ideas are credited below.

- **SegFormer / MiT:** Xie et al., *SegFormer: Simple and Efficient Design for Semantic Segmentation with Transformers*, NeurIPS 2021. [Paper](https://arxiv.org/abs/2105.15203), [official repository](https://github.com/NVlabs/SegFormer). The pretrained-derived weights retain the NVIDIA research/evaluation license; see `licenses/SegFormer.txt`.
- **UPerNet:** Xiao et al., *Unified Perceptual Parsing for Scene Understanding*, ECCV 2018. [Paper](https://arxiv.org/abs/1807.10221), [official repository](https://github.com/CSAILVision/unifiedparsing).
- **clDice:** Shit et al., *clDice — A Novel Topology-Preserving Loss Function for Tubular Structure Segmentation*, CVPR 2021. [Paper](https://arxiv.org/abs/2003.07311). The release implements a soft-skeleton connectivity objective with binary GT skeletons and explicit padding handling.
- **ProMSC:** [djene-mengistu/ProMSC](https://github.com/djene-mengistu/ProMSC), the author's earlier framework and source of the original MiT/UPer architecture components used during experimentation. This UAV code does not claim to reproduce the full ProMSC method.
